# sops_entry (Resource)

Manage specific key/value entries in an existing SOPS-encrypted file. Inserts entries if missing, updates if changed. Unchanged values preserve their ciphertext via SOPS IV stash mechanism.

## Example Usage

```terraform
provider "sops" {}

resource "sops_entry" "secrets" {
  file = "config.enc.yaml"

  entries = {
    db_password    = var.db_password
    api_key        = var.api_key
    redis_password = var.redis_password
  }
}

output "all_config" {
  value     = resource.sops_entry.secrets.data
  sensitive = true
}
```
